## Описание
В рамках проектной работы требуется разработать мобильное приложение для организации и контроля доступа на закрытые мероприятия.  
Приложение должно помогать создавать мероприятия, приглашать гостей и фиксировать их вход и выход по QR-коду.

---

## Цели проекта
Приложение должно уметь:
- создавать мероприятия;
- рассылать приглашения;
- сканировать QR-коды;
- помечать вход и выход гостя.

---

## Роли в системе
В приложении должны быть реализованы две роли:
1. **Администратор** — управляет мероприятиями и списками гостей, отправляет приглашения.
2. **Валидатор** — выполняет проверку гостей на входе и выходе (сканирование QR-кодов и отметки).

---

## Функциональные требования
Приложение должно поддерживать:

- **Добавление гостей**:
  1. из контактной книги устройства;
  2. вручную.

- **Добавление мероприятий** с полями:
  1. название мероприятия;
  2. дата;
  3. время;
  4. адрес;
  5. уникальная ключевая фраза.

- проверку наличия гостя в списках мероприятия;
- возможность использования многоразовых QR-кодов.

---

## Основные этапы работы приложения
- авторизация пользователя;
- обработка данных:
  1. добавление данных в базу данных (БД);
  2. обработка данных (проверки, отметки входа/выхода и т.д.).

---

## Технологии
- **Android Studio** — среда разработки;
- **Google Firebase** — база данных и backend-сервисы;
- **Java + XML** — разработка Android-приложения.
